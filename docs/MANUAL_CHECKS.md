# DinoPlayer 0.41 — manual checks

1. **Controls and type:** open portrait and landscape videos. Check that titles and settings use normal Android fonts, top actions remain reachable, the timeline is usable, paused controls stay visible, and PiP hides caption progress notices.
2. **Cancel / Retry:** start generation, tap the top Stop button during extraction or recognition, and wait for “Cancelled · Retry.” Video playback should continue. Tap Retry and confirm the Stop button is available immediately and captions resume in sync. Repeat with captions hidden. Check that a cancelled job does not silently restart after visiting Settings.
3. **Status and interruption:** check the library’s selected-language status. Start generation, leave the player before completion, reopen it, and choose Retry. Previously completed chunks should be recovered. A no-audio/no-speech video should report Failed and allow retry.
4. **Editor:** after generating captions, open Edit / export. Change text and one caption’s times, apply a positive and negative global shift, and save. Reopen the video and verify the edited captions. Confirm invalid or overlapping times are rejected. Check Back → Save / Discard / Keep editing.
5. **Export:** export both SRT and VTT to a chosen folder. Open the exported files and check text and times. Cancel the file picker and try again. If available, test Android recreating the editor while the picker is open; the loaded captions must be exported rather than an empty file.
6. **Regenerate and cache:** edit/save captions, clear the disposable cache in Settings, and verify the saved edit remains. Regenerate and confirm edits are replaced only after successful generation. A failed/cancelled regeneration should leave the previous saved copy intact.
7. **Deletion:** use a disposable copy of a video. Start generation, return to the list, choose Delete, and deny Android’s approval: the actual video and row must remain and generation must stop. Retry and approve deletion: verify the physical file is gone and the list refreshes. Repeat with DinoPlayer subtitle cleanup checked and unchecked; exported and separate sidecar subtitles must remain.
8. **Automatic generation:** turn “Generate subtitles for new videos” on in Settings with an offline pack installed. Existing videos should be skipped. Add a new video; expect Queued → Generating → Ready, allowing for Android’s background scheduling. Open a different video during background generation: playback should take priority. Turn the setting off and verify pending automatic work is cancelled. With the selected pack absent, new videos should wait in Queued until that pack is installed.
9. **Library regression:** scroll the main library and open a folder; it should start at the top. Back should restore the main list position. Check search, last-watched highlight, dull completed rows, and partially/full-filled watch progress bars after playback and after deleting a video.

Automatic generation for new additions and automatic live generation while watching are separate settings. A force-stopped app needs to be opened again before Android can resume its background work. Existing device behavior was not exercised in this build-only pass.

## Appearance (0.43)

Check Settings → Subtitle appearance and the player shortcut. Try every size/colour, opacity/spacing extremes, outline toggle, Android style override, restart persistence and Reset to default. Compare live/saved/imported captions across rotation, visible/hidden controls and PiP. Bitmap captions retain their artwork.
