# Changelog

## 0.43 — Initial DinoPlayer public preview

DinoPlayer builds on Just Player with a searchable folder library, watch history/progress, revised green branding and playback controls, optional on-device subtitle packs, live incremental caption display, recoverable jobs and safe video deletion. It includes a subtitle editor/exporter and global appearance preferences with live preview.

- 0.43: Subtitle appearance preferences and preview; 49 host unit tests.
- 0.42: Shared rendering style for live, saved and imported text captions.
- 0.41: Cancellation/Retry, durable job states, optional new-video jobs, file deletion, subtitle editing/export, and control/font cleanup.
- 0.40: Non-obstructive caption progress indicator.
- Earlier DinoPlayer work: library/search/watch progress, bounded caches, pinned optional caption packages, and incremental media-time cues.

The initial downloadable APK is the installed debug-signed 0.43 build. Translation remains experimental; device coverage is limited. The inherited Just Player commits remain in repository history.
